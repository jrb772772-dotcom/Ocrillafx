
# OCRILLA FX AI

A professional AI-inspired forex signal platform concept.

## Features
- BUY / SELL signals
- TP1, TP2, TP3, TP4
- Stop Loss
- Confidence scoring
- Multi-market support
- TradingView integration ready
- Telegram alert support
- Responsive dashboard

## Tech Stack
Frontend:
- Next.js
- Tailwind CSS

Backend:
- Python FastAPI

## Important
No trading system can honestly guarantee 85%+ live win rates permanently.
This project is designed to maximize probability using strong filtering and risk management.

## Run Frontend
```bash
npm install
npm run dev
```

## Run Backend
```bash
pip install fastapi uvicorn
uvicorn main:app --reload
```
